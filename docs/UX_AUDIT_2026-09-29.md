# Auditoría UX de Tapa Racing — 29 septiembre 2026

## Alcance y método

Se revisaron las rutas y estados implementados en el menú principal, carrera rápida, selección de tapas y pistas, Garage, copas, preparación de copa, carrera, pausa, resultados, premios, desafíos y ajustes. También se comprobaron el retroceso de Android, persistencia de selección, estados bloqueados y pruebas responsive existentes.

Las pantallas de perfil y ranking no existen como flujos independientes en la versión actual. La progresión del jugador aparece en la cabecera, Garage, resultados y copas.

## Mapa actual de navegación

```text
INICIO
├─ JUGAR → Preparación rápida → Carrera → Resultados
│                                  ├─ Volver a correr
│                                  └─ Volver al menú
├─ COPAS → Mapa de copa → Preparación → Carrera de copa
│                                      → Resumen → Mapa / siguiente ronda
├─ PISTAS → Selector → Preparación rápida → Carrera
├─ TAPAS → Garage
├─ PREMIOS → Desafíos
└─ AJUSTES

Durante una carrera
└─ Pausa → Continuar / Reiniciar / Volver al menú
```

Android Back vuelve al inicio desde las secciones del menú, vuelve al mapa desde la preparación de copa y alterna la pausa durante la carrera. Las selecciones de tapa y pista se guardan.

## Hallazgos por pantalla

|---|---|---|---|

| Garage | Equipar, mejorar o desbloquear | Equipar, mejorar, habilidad, apariencia, selector numérico y desbloqueo compiten; las estadísticas usan términos técnicos y muchos datos simultáneos | Alto |

## Problemas transversales

1. La preparación rápida no responde en tres segundos qué pista y tapa se usarán ni ofrece cambios directos.
2. Las acciones principales y secundarias comparten con frecuencia el mismo estilo y altura.
3. Existen términos duplicados: Pista/Circuito, Turbo/Boost, Ajustes/Configuración y Repetición/ghost.
4. El flujo libre termina en Repetir o Menú; falta una continuación hacia otra pista.
5. Reiniciar o abandonar una carrera puede ocurrir sin confirmación.
6. No existe onboarding persistente para el primer uso; las instrucciones se muestran completas cada vez.
7. Los estados sin récord dicen “sin marca” o “por descubrir”, pero no siempre indican “completa una carrera”.
8. Garage presenta toda la información al mismo tiempo y aumenta el tiempo necesario para identificar la acción disponible.
9. Varias rutas vuelven al inicio y pierden el contexto de la tarea anterior.
10. Estrellas, color y texto se combinan de forma irregular; algunos estados dependen demasiado del color.

## Vocabulario oficial propuesto

Tapa, Carrera, Copa, Pista, Garage, Mejora, Nivel, XP, Monedas, Habilidad, Turbo, Récord, Desafío, Recompensa y Repetición.

Usar “Control” en estadísticas, “Turbo” en lugar de Boost, “Pista” en lugar de Circuito para interfaz y “Ajustes” en navegación y títulos. “Ghost” queda reservado al código interno; para el jugador se usa “Repetición”.

## Flujo propuesto

```text
INICIO
├─ JUGAR → LISTO PARA CORRER
│          ├─ CORRER AHORA
│          ├─ Cambiar pista → volver a LISTO PARA CORRER
│          └─ Cambiar tapa  → volver a LISTO PARA CORRER
│             ↓
│          CARRERA → RESULTADOS
│                    ├─ SIGUIENTE PISTA
│                    ├─ JUGAR DE NUEVO
│                    └─ MENÚ
└─ COPAS → Copa → Pista disponible → Preparación → Carrera
                                             ↓
                                 Resultado → SIGUIENTE CARRERA
```

Este flujo conserva todas las funciones y reduce los regresos innecesarios al inicio.

## Pasos que pueden eliminarse

- Volver al inicio para cambiar la tapa desde la preparación rápida.
- Volver al inicio para cambiar la pista desde la preparación rápida.
- Volver al inicio entre una carrera y la siguiente pista.
- Entrar a Premios solo para saber si hay desafíos listos para reclamar; el contador puede mostrarse en el acceso.

## Prioridades

1. **P0 — Flujo JUGAR:** resumir pista, tapa, dificultad, objetivo y récord; añadir cambios contextuales; destacar CORRER AHORA.
2. **P0 — Navegación segura:** confirmar reinicio y salida de carrera; unificar Android Back y botones visibles.
3. **P1 — Resultados:** dar prioridad a la siguiente acción, añadir siguiente pista y jerarquizar repetir/menú.
4. **P1 — Garage:** mostrar primero estado, habilidad y costo; mover detalle técnico a un panel contextual.
5. **P1 — Copas:** destacar progreso, próxima pista y recompensa; reducir texto secundario.
6. **P2 — Primera experiencia:** instrucciones contextuales de una sola vez y opción de ayuda.
7. **P2 — Premios y desafíos:** mostrar recompensas reclamables desde el primer nivel.
8. **P2 — Accesibilidad y microcopy:** terminar unificación de vocabulario, foco, estados no basados solo en color y textos vacíos.

## Primera implementación

La primera mejora se concentra en la preparación de carrera rápida porque afecta la acción más frecuente. Debe mostrar en un solo vistazo pista, tapa, dificultad, vueltas, objetivo y récord; ofrecer Cambiar pista y Cambiar tapa con regreso al mismo contexto; acortar las instrucciones; y reservar la mayor jerarquía para CORRER AHORA.
